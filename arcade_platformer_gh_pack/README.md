# Arcade Platformer – GitHub‑ready Pack

This bundle contains:

* Phaser 3.88 starter code
* Placeholder graphics (ground, coins, 3‑frame hero)
* Arcade‑style SFX (jump, coin) and looping chiptune BGM

## Quick deploy

1. Create a GitHub repo, drag‑drop contents, commit.
2. Repo → Settings → Pages → Deploy from *main*.
3. Visit `https://<user>.github.io/<repo>/`.

Swap out everything in **assets/** with real art & audio when you’re ready.
